Finger Master v1.6  ―  Maya 2022以降 指マスターリグツール
==========================================================

既存の指FKリグに、握る・開く・ポーズなどの操作を後付けするツールです。
元のリグは変更しません。いつでも元に戻せます。


■ インストール
--------------
1. zipを解凍する。
2. Mayaで、ボタンを置きたいシェルフのタブを開く。
3. install.mel をMayaのビューポートにドラッグ＆ドロップ。
4. シェルフに手のアイコンが追加され、パネルが開きます。

  * アップデート: 新しい install.mel を同じようにドロップするだけ。


■ シェルフボタン
----------------
  左クリック    パネルを開く
  右クリック    Build from selection    選択から作成
                Open example scene      サンプルシーンを開く
                Uninstall Finger Master アンインストール


■ セットアップ
--------------
1. 各指の「根元のジョイント」（または根元のコントローラー）を選択。
   左右の手をまとめて選択してもOK。
2. パネルの Build を押す。
   チェーン・左右・指の種類は自動で判別されます。
   上部に「L 16/16 joints follow」と出れば成功です。

  * 元のリグ（リファレンス前のファイル）で作成するのがおすすめです。
  * リファレンスされたリグにも作成できます。


■ パネル
--------
  手の図      指をドラッグ: 上下 = 曲げ、左右 = 開き
              手のひらをドラッグ: 手全体
              クリック: その指のタブへ / ダブルクリック: リセット
  PRESETS     Fist / Grab / Open / Relax（手全体を上書き）
  HAND        手全体のスライダー（握る・開く・順番に握る・すぼめる・リラックス・関節ごとの曲げ）
  FINGER      1本ずつの曲げ / 開き / ねじり、FK / IK 切替
              薄い長いバー + 数字 = その指の実際の量（全部込み）
              細いバー = その指自身のスライダー
              Base / Mid / Tip = その指の根元 / 中間 / 指先の関節だけ曲げる（マイナス = 反らす）
              （古いバージョンで作った手は Rebuild を一度押すと表示。ポーズとキーは残ります）
              Thumb タブの Grasp: 親指の握り軸（Auto / X / Y / Z / Flip）
  POSES       + Save: 今の手の形をポーズとして保存
              クリック: そのポーズに切替（もう一度クリックでオフ）
              左右ドラッグ: ポーズの量（下の細いバー）
              右クリック: キー / スライダーへ反映 / 更新 / 削除

  スライダー操作: ドラッグで設定、ダブルクリックで0、右クリックでキー
  赤い点 = キーあり


■ キー
------
  Auto Key    Mayaのオートキーと同じスイッチ。パネルでの変更は手全体まとめてキー。
  Key         手全体を現在フレームにキー。


■ IK
----
  FINGER の IK を押すと、緑のキューブが指に合わせてから切り替わります（ポーズは飛びません）。
  キューブ移動 = 指先の位置 / キューブ回転 = 指先の向き / ボール = 関節の曲がる方向
  ※ IK中は元のFKコントローラーの回転を0にしておくのがおすすめ。


■ ベイク（最後の工程）
----------------------
  Bake を押すと、アニメーションを元のFKコントローラーに焼き込みます。
  Frames              ベイクするフレーム範囲
  Every frame         毎フレームキー（正確）
  Keyed frames only   キーのあるフレームのみ（カーブがきれい）
  Remove Finger Master  ベイク後にツールを削除（オフ = ツールを残して0に戻す）
  Both hands          両手まとめてベイク


■ うまく動かないとき
--------------------
  Check を押す（自動で修正を試みます）。
  それでもダメなら、指の根元ジョイントとコントローラーを選択して
  Script Editor（Python）で実行し、出力を開発者に送ってください:
      import fingerMaster as fm; fm.diagnose()


■ 削除
------
  Remove      シーンからこの手のMasterを削除。元のリグに完全に戻ります。
  Uninstall   シェルフ右クリック → Uninstall Finger Master（ツールのみ削除、シーンはそのまま）
