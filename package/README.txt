Finger Master  v1.6  —  Maya 2022+ 手指 Master 绑定工具
=====================================================

在已有的手指 FK 绑定上叠加一层 Master 控制:
握拳 / 展开 / 依次握拳 / 收掌 / 放松、单指控制、手指 IK、姿势库。
不改动原绑定, 随时可以移除还原。


■ 安装 (约 10 秒)
-----------------
1. 解压这个 zip (解压到哪里都可以, 装完可以删掉)。
2. 打开 Maya, 先点到想放按钮的那个工具架 (shelf) 标签。
3. 把 install.mel 拖进 Maya 的视窗里。
4. 工具架上出现手形图标的 "FingerMaster" 按钮, 面板会自动打开。

  * 更新: 用新版安装包再拖一次 install.mel, 会覆盖旧版, 不会重复加按钮。
  * 装到了: 文档\maya\<版本>\scripts\fingerMaster.py
            文档\maya\<版本>\prefs\icons\fingerMaster.png


■ 工具架按钮
-----------
  左键          打开面板
  右键菜单      Open Finger Master      打开面板
                Build from selection    直接用当前选择建立
                Open example scene      打开示例场景 (练手用)
                Uninstall Finger Master 卸载


■ 使用
------
1. 在大纲里选中每根手指的「根骨骼」(或根部控制器), 左右手可以一起选。
   控制器之间是父子关系、还是平铺 + 约束都可以, 会自动识别。
   绑定是引用 (reference) 进来的也可以 (不改动层级, 用 offsetParentMatrix 叠加)。
2. 点面板上的 Build。
   Build 完会自动自检: 逐节测试「转控制器 / 拉 Master」骨骼会不会动,
   面板顶部显示  L 16/16 joints follow  这样的结果 (详细在 Script Editor)。
   如果你的绑定直接读控制器的数值 (ctl.rotate / ctl.matrix -> 骨骼),
   会自动改成「直接叠加」模式, 不需要手动设置。
3. 调手型:
   - 手的图:   拖手指 上下 = 弯曲, 左右 = 张开; 拖手掌 = 整只手; 点手指 = 切到该手指
               双击 = 归零; 右键 = 选 FK 控制器 / 切 IK
   - PRESETS:  握拳 / 抓握 / 张开 / 放松, 点一下平滑过渡 (完整手型: 单指滑条和姿势一起归零)
   - HAND:     整手滑条. 拖动设置, 双击归零, 右键 K 帧. 红点 = 有关键帧
   - FINGER:   单指的弯曲 / 左右 / 扭转, 以及 FK / IK 切换
               浅色长条 + 数字 = 这根手指现在实际的总量 (预设 / 整手 / 姿势 / IK / FK 全部算进去)
               中间的细实心条 = 这根手指自己的滑条 (拖动改的是这个)
               Base / Mid / Tip = 只弯这根手指的根节 / 中节 / 指尖, 负数 = 反折
               (旧版建立的手点一次 Rebuild 才会出现, 姿势和关键帧保留)
               Thumb 标签里的 Grasp: 拇指抓握轴 Auto / X / Y / Z + Flip
               (骨骼朝向因项目而异, 自动不对时手动选; 会自动重建, 姿势和关键帧保留)
   - POSES:    + Save 把当前手型存成姿势. 每个姿势在 Master 上有一个 0~100% 的权重 (可 K 帧)
               卡片下方的滑块 = 这个姿势的百分比; 多个姿势加起来最多 100%
               100% = 手型完全等于这个姿势 (滑条不起作用); 50% = 滑条手型和姿势的正中间
               点卡片的手型图 = 平滑切到这个姿势 100% (再点一次 = 关掉)
               姿势开着时去调滑条: 会先把看到的手型写回滑条, 再继续调 (不会跳)
               右键 = K 整只手 / 写回滑条 / 用当前手型更新 / 删除
               已经有动画时新存姿势: 新姿势在之前所有关键帧上自动 K 成 0, 之前的动画不受影响
               注意: 姿势只记录 Master 的滑条, 不包含 FK 控制器自己的旋转
4. Auto Key 打开时 (与 Maya 的自动关键帧同一个开关), 面板里的改动都会自动 K 帧,
   而且整只手 (整手 + 单指 + IK + 姿势) 一起 K, 之后再改单指也不会让之前的关键帧变样。
   Key = 给整只手 K 一帧。


■ IK
----
在 FINGER 里点 IK: 先把绿色方块对齐到手指, 再切换 (不会跳), 并自动选中方块。
  移动方块 = 指尖位置;  旋转方块 = 指尖朝向;  小球 = 指关节弯曲方向
  Blend 条可以 K 帧, 做 FK <-> IK 的过渡。
  注意: IK 模式下原 FK 控制器若有旋转, 会叠加在 IK 上, 建议保持为 0。


■ Bake (最后一步)
----------------
动画做完后点 Bake, 把 Finger Master 的效果烘焙到原绑定的 FK 控制器上:
  Frames                   烘焙的帧范围 (默认 = 时间轴范围)
  Every frame              每一帧都 K (最准确)
  Keyed frames only        只在有关键帧的帧 K (曲线更干净, 中间帧有很小的插值差别)
  Remove Finger Master     烘焙后移除工具 (默认). 不勾 = 保留工具, 但清掉它的关键帧并归零
  Both hands               左右手一起烘焙
烘焙后的结果和烘焙前逐帧一致, 原绑定可以单独交付 / 导出。


■ 不起作用时
-----------
  点 Check 重新检查 (会自动修)。还是不行的话, 选中一根手指的根骨骼和它的控制器,
  在 Script Editor (Python) 运行:   import fingerMaster as fm; fm.diagnose()
  把输出的文字发给开发者即可。


■ 移除 / 卸载
------------
  Remove        把场景里这一侧的 Master 去掉, 原绑定完全还原。
  Uninstall     工具架右键菜单 -> Uninstall Finger Master (只删工具, 不动场景)。


■ 不用安装直接运行
------------------
在 Script Editor 的 Python 标签里:
    import sys; sys.path.append(r"<解压路径>/FingerMaster/scripts")
    import fingerMaster as fm; fm.ui()
